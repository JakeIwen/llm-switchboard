  • word in the title, first prompt, folder, id or Remote Control name; "two words" for a phrase
  • -word excludes; works with everything below too, e.g. -dir:tmp
  • dir:obd folder · title:telem · id:c969

  • age:<2d active in the last 2 days · age:>1w older than a week (units m h d w)
  • state:backoff exact supervisor state

Keys: ↑↓ move · Space select · ⇧+↑↓ extend · ⌘/Ctrl+A all · Enter details · ⌫ delete · Esc clear · / search · n new session. Click selects; ⌘/Ctrl-click adds; ⇧-click selects a range.

Enabled sessions are resumed through claudepd … --remote-control in tmux, relaunched if they exit, and started again at boot.
